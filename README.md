## Vishnu Konga

Mechanical design and robotics - CAD, prototyping, and the code that runs it.

Most of my work starts as a mechanism: a part in CAD, a prototype on the bench,
and a few iterations figuring out why the two don't match. Software usually
shows up in service of that - control code, tooling, and whatever the project
needs to actually run.

**Working with**

- CAD and mechanical design - parts, assemblies, tolerancing
- Robotics - mechanisms, drivetrains, controls
- TypeScript and React when something needs a screen

**Currently**

- [exo-arm](https://github.com/VK12034/exo-arm) - apPowered elbow exoskeleton: small NEMA 23 stepper through a 30:1 worm and 2:1 chain, Arduino firmware, Fusion CAD and build docs.
